# BeagleY-AI / Arducam B0310 IMX708 720p60 R2

Date: 2026-08-25

This checkpoint converts the qualified IMX708 R1 path from 2304x1296p56 output
into the intended OpenHD 1280x720p60 path while preserving the same CSI0,
RAW10LE compatibility runtime, VPAC/VISS, Wave5, and RF boundaries.

## Why 1536x864p60

The exact Beagle 6.12.49 IMX708 driver exposes a 1536x864 2x2-binned/cropped
mode with:

- line length: 0x1460 = 5216 pixels
- pixel rate: 566400000 pixels/s
- minimum VBLANK: 40 (~120 fps)
- programmable VBLANK

For a requested 60 fps cadence:

```
fps = pixel_rate / (line_length * (height + vblank))
```

`VBLANK=946` yields approximately 59.9939 fps. R2 therefore runs the sensor
itself at ~60 fps instead of capturing 120 fps and dropping every other frame.
That halves CSI/ISP work relative to the 120-fps mode and avoids a `videorate`
stage in the low-latency path.

## R2 camera contract

```
sensor        IMX708 / Arducam B0310
CSI           CSI0, 2 lanes
input         1536x864 SRGGB10
vblank        946
nominal rate  60 fps (59.9939 calculated)
V4L2 fourcc   RG10
GStreamer     rggb10le
TIOVX caps    rggb10
format-msb    9
DCC geometry  1536x864
```

The existing IMX708 RAW10LE compatibility runtime remains valid; no new TI core
patch is required.

## R2 ISP / encode path

```
IMX708 1536x864 RAW10 @ 60
  -> TI CSI2RX / DMABUF import
  -> capssetter rggb10le -> rggb10 metadata compatibility
  -> VPAC/VISS 1536x864 NV12 @ 60
  -> TIOVX multiscaler
  -> 1280x720 NV12 @ 60
  -> queue depth 1 / leaky downstream
  -> Wave5 H.264 @ 6 Mbit/s, GOP 30
```

AE/AWB remain disabled while the TI userspace uses the IMX219 registry/DCC slot
for compatibility. The IMX708 1536x864 DCC files are resolution-specific and
must be generated before live VISS qualification.

## DCC generation

On the same x86_64 host used for R1 DCC generation:

```
./scripts/build-imx708-default-dcc.sh --mode 1536x864
```

Install the resulting files as:

```
/opt/imaging/imx708/linear/dcc_viss_1536x864.bin
/opt/imaging/imx708/linear/dcc_2a_1536x864.bin
```

The previous 2304x1296 generator mode is retained with `--mode 2304x1296`.

## Live qualification order

1. Install/copy the R2 graph and smoke helpers.
2. Generate/install 1536x864 DCC.
3. Verify raw sensor cadence:
   ```
   ti-k3-configure-imx708-graph --mode 864p60 --verify-stream --verify-frames 600
   ```
   Expect approximately 10 seconds for 600 frames and no new kernel errors.
4. Run VISS only:
   ```
   FRAMES=600 ti-k3-imx708-viss-smoke
   ```
5. Run complete local hardware path:
   ```
   FRAMES=600 ti-k3-imx708-wave5-720p60-smoke
   ```
6. Decode/inspect the generated H.264 file locally.
7. Only after local success, install the matching OpenHD R2 branch and run RF.
